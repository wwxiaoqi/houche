# grid · 格纸

**气质**：冷灰底上铺一块稍深的实色面板，面板描边色等于面板底色，边界退成一条几不可见的分界。

**适合**：工具集、清单、批量操作与表单参数页，信息密度高的界面。

**不适合**：需要留白和情绪表达的阅读、记账场景；紧凑密度在小屏上会显得挤。

**结构特征**：四套里唯一 `kit_density=compact`，也是唯一 `kit_card=fill` 且 `cardStroke` 与 `card` 同色（描边退化成底色）；按钮是 12dp 方肩款（`kit_button=rect`），字阶 0.96 是四套里最小的。它没有渐变，靠实色面板而不是发丝线或描边分层。
